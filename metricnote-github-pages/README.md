# Metric Note GitHub Pages 업로드 파일

이 폴더 안의 파일과 폴더를 **구조 그대로** `metricnote/metricnote.github.io` 저장소의 `main` 브랜치 루트에 업로드합니다.

## GitHub 웹에서 업로드하기

1. 저장소에서 `Add file` → `Upload files`를 선택합니다.
2. 이 폴더 안의 `_config.yml`, `index.md`, `_posts`, `assets`, `files`를 업로드합니다.
3. `Commit changes`를 누릅니다.
4. `Settings` → `Pages`에서 `Deploy from a branch`, `main`, `/(root)`를 선택합니다.
5. 배포가 끝나면 <https://metricnote.github.io>에서 확인합니다.

`README.md`는 사용 안내 파일이므로 같이 올려도 되고 제외해도 됩니다.
